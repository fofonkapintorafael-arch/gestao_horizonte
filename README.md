## Projeto Horizonte 
# A Horizonte Soluções, uma empresa que comercializa produtos e presta serviços, cresceu rapidamente. Atualmente, seus colaboradores controlam clientes, produtos, pedidos e relatórios por meio de anotações e planilhas separadas. O resultado são cadastros duplicados, informações desencontradas e dificuldades para acompanhar a operação. 

# OBJ: o protótipo de um Sistema de Gestão Empresarial.
# Funcionalidades: O sistema deverá apresentar páginas simples, navegáveis, com informações fictícias e uma identidade visual coerente.

# Tecnologias utilizadas: arquivos html, css, Git e GitHub.
# Requisitos para visualizar as páginas: clicar nos links gerados do projeto.
