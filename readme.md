# Funcionamento e Documentação do projeto "Gestão Horizonte"

 Qual será o nome do projeto e a situação problema que ele busca resolver?

 O nome do projeto sera: Gestão Horizonte 
 Qual é o problema repassado: A empresa Horizonte Soluções que comercializa produtos e presta serviços, cresceu rapidamente. Atualmente, seus colaboradores controlam clientes, produtos, pedidos e relatórios por meio de anotações e planilhas separadas. O resultado são cadastros duplicados, informações desencontradas e dificuldades para acompanhar a operação.
